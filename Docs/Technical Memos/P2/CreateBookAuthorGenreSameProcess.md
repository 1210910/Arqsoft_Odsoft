# Technical Memo: Creating Book, Author, and Genre in the Same Process

| **Element**        | **Statement**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
|---------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Stimulus**        | The need for a streamlined process to create a <span style="color:lightblue">**Book**</span>, <span style="color:lightblue">**Author**</span>, and <span style="color:lightblue">**Genre**</span> simultaneously, improving efficiency and user experience for librarians.                                                                                                                                                                                                                                                                                                                                                                                                      |
| **Stimulus Source** | Librarians require a unified workflow to manage book-related data efficiently, reducing the time and effort needed to input related information separately.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| **Environment**     | The application operates in a microservices architecture, with dedicated services for managing <span style="color:lightblue">**Books**</span>, <span style="color:lightblue">**Authors**</span>, and <span style="color:lightblue">**Genres**</span>.                                                                                                                                                                                                                                                                                                                                                                                                                           |
| **Artifact**        | The LMS Software, specifically the book management functionality, now supports the creation of a <span style="color:lightblue">**Book**</span>, <span style="color:lightblue">**Author**</span>, and <span style="color:lightblue">**Genre**</span> in a single transaction.                                                                                                                                                                                                                                                                                                                                                                                                    |
| **Response**        | Implemented a unified process within the book management module that allows librarians to input details for a <span style="color:lightblue">**Book**</span>, <span style="color:lightblue">**Author**</span>, and <span style="color:lightblue">**Genre**</span> concurrently. This ensures that all related entities are created and linked together seamlessly. This also mantains consistency with the AMQP communication because every <span style="color:lightblue">**Book**</span>, <span style="color:lightblue">**Author**</span> and <span style="color:lightblue">**Genre**</span> are still going to be sent to the other Microservices when the process is ongoing. |
| **Response Measure** | The success of this feature is measured by the reduction in the time taken by librarians to input book-related data and the increased accuracy and consistency of the data entered.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
