# Technical Memo: Decision to Use Docker Swarm

| **Element**        | **Statement**                                                                                                                                                                                                                                                                                                                                                                |
|---------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Stimulus**        | The need for improved orchestration, scalability, and management of containerized applications beyond the capabilities of `docker-compose up`.                                                                                                                                                                                                                               |
| **Stimulus Source** | The limitations of using `docker-compose up` for each instance, which include manual scaling, lack of service discovery, and difficulty in managing multiple containers across different hosts.                                                                                                                                                                              |
| **Environment**     | The application operates in a microservices architecture, with numerous services that need to be deployed, scaled, and managed efficiently across multiple nodes.                                                                                                                                                                                                            |
| **Artifact**        | The container orchestration strategy for the LMS Software, transitioning from `docker-compose up` to Docker Swarm.                                                                                                                                                                                                                                                           |
| **Response**        | Adopt Docker Swarm for container orchestration to enable automated scaling, service discovery, load balancing, and easier management of containerized applications. Docker Swarm provides a robust and scalable solution for managing microservices across multiple nodes.                                                                                                   |
| **Response Measure** | The effectiveness of this decision is measured by the ease of deployment, the ability to scale services up or down automatically, improved service discovery and load balancing, and the overall reduction in deployment and management time. The notorious downside was the lost of control about the `depends on`. There are some instabilities with the use of the Swarm. |
