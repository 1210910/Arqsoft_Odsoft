# Technical Memo: Conversion to Microservices

| **Element**        | **Statement**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
|---------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Stimulus**        | The monolithic architecture limits scalability and maintainability, making it necessary to separate concerns into distinct collaborating applications to support distributed development and deployment.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| **Stimulus Source** | The need to transition from a monolithic architecture to a distributed system aligned with business domains, enabling better scalability, fault isolation, and team autonomy.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| **Environment**     | The application operates in a microservices architecture, utilizing patterns like CQRS, database-per-service, and messaging, with RabbitMQ as the AMQP broker for inter-service communication.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| **Artifact**        | The LMS Software, originally a monolithic application, now redesigned into microservices.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| **Response**        | Segregate the monolith into the following microservices: <span style="color:lightblue">**Books**</span>, <span style="color:lightblue">**Readers**</span>, and <span style="color:lightblue">**Lendings**</span>, each responsible for a distinct domain. Additional microservices were created for <span style="color:lightblue">**Top5**</span> (optimized heavy-query handling) and <span style="color:lightblue">**Auth & Users**</span> (authentication and user management). Adopted design patterns to enhance the architecture:                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| **Design Patterns** | <span style="color:lightblue">**Strangler Fig**</span>: Partially used while gradually migrated functionality from the monolith to microservices, since we had the teacher's example to begin our conversion. Some implementations were done by mixing the monolith app running to test the newly microservice functionality, however, there was no API gateway or reroute used in this gradual replacement of the monolith system. <br> <span style="color:darkgreen">**CQRS**</span>: Separated read and write (query and command) operations into distinct models, optimizing performance and scalability. <br> <span style="color:darkgreen">**Database per Service**</span>: Ensured each microservice has its own database, promoting loose coupling, data autonomy, and independent scalability. <br> <span style="color:darkred">**Polyglot Persistence**</span>: Utilized multiple data storage technologies to optimize for different types of data and access patterns, leveraging the strengths of each database technology. <br> <span style="color:darkgreen">**Messaging**</span>: Adopted RabbitMQ for asynchronous communication between microservices, decoupling services and enabling independent operation. <br> <span style="color:darkgreen">**Domain Events**</span>: Represented significant changes within a domain using domain events, ensuring decoupled reactions to changes and promoting an event-driven architecture. <br> <span style="color:darkgreen">**Saga**</span>: Implemented the Saga pattern to manage distributed transactions across multiple microservices, ensuring data consistency and handling complex workflows. |
