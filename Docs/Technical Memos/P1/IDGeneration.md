# Technical Memo: Implementing ID Generation Methods

---
| Element   | Statement                                                                                                                                                                                                                                                                                                                                          |
|-----------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Stimulus  | The requirement for generating unique IDs for entities within the application.                                                                                                                                                                                                                                                                     |
| Stimulus Source | The product owner wants the application to create distinct identifiers for every entity to maintain data integrity and facilitate efficient data handling.                                                                                                                                                                                         |
| Environment | The ID generation must be flexible enough to support various approaches while ensuring ease of use and consistency across different entities.                                                                                                                                                                                                      |
| Artifact  | The LMS Software, especially the Domain Classes that will have a new attribute.                                                                                                                                                                                                                                                                    |
| Response  | Create a new attribute on the entities that will carry this new ID to be generated and an interface for ID generation methods, allowing multiple implementations that adhere to different ID generation strategies. Utilize Spring Boot’s @Profile annotation to configure the active ID Generation Strategy dynamically based on the environment. |
| Response Measure | The application should allow for the seamless switching of ID generation strategies based on configuration within 30 minutes.                                                                                                                                                                                                                      |

---
