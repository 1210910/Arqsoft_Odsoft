# Technical Memo: Implementing Multiple Authentication/IAM Services

| Element   | Statement                                                                                                                                                                                                                                                                                                  |
|-----------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Stimulus  | The requirement to support multiple authentication services for user access.                                                                                                                                                                                                                               |
| Stimulus Source | The product owner needs distinct IAM solutions.                                                                                                                                                                                                                                                            |
| Environment | The application needs to provide flexible authentication options, for example, Google Firebase, Azure Active Directory, Facebook (Meta), while maintaining a unified codebase to reduce redundancy and simplify maintenance.                                                                               |
| Artifact  | The LMS Software, specifically the authentication layer.                                                                                                                                                                                                                                                   |
| Response  | Create an interface for authentication services providers, allowing multiple implementations of the method authenticate of the system, for example, through Google Firebase and Azure. Utilize Spring Boot’s @Profile annotation to configure the active IAM service dynamically based on the environment. |
| Response Measure | The application should seamlessly switch between authentication services based on configuration within 30 minutes.                                                                                                                                                                                         |
